'

El proyecto tiene un ROADMAP.md que define los pasos de implementación.

Objetivo de este chat:

[PEGA AQUÍ EL TEXTO DEL PUNTO DEL ROADMAP]

- Mantener la solución simple y educativa.
- Evitar tecnologías innecesarias para esta etapa.
- Priorizar claridad, mantenibilidad y aprendizaje.

- Criterios de completitud verificables.
